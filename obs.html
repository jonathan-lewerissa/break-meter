OBS overlay 🎱

A transparent Break Meter for an OBS Browser Source: big speed readout, gap time and session best. It arms the mic as soon as it loads — no buttons.

Preview in a new tab ↗

Setup

  1. Launch OBS with the --enable-media-stream flag — OBS blocks mic access in browser sources by default.
    • Windows: right-click the OBS shortcut → Properties, append the flag to the Target field.
    • macOS: open -a OBS --args --enable-media-stream, then allow OBS the microphone in System Settings → Privacy & Security.
  2. Add a Browser Source and paste the URL above.
  3. Untick Shutdown source when not visible so it keeps listening between scenes.

If the readout shows Mic error, the flag or the OS permission isn't in effect. The overlay uses whichever mic the OBS machine has, so put it near the table.
